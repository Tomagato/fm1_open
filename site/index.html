BEACH 909

A one-page 909-style drum machine for the M-VAVE FM-1: eight drums, sixteen steps, reverb and delay, a vapor button and a block game, under a pixel sunset.

Unofficial firmware, not yet validated on hardware. Installing it is at your own risk. Read the terms below before you update.

Open the install page Download .fwsc Source

INSTALL

  1. Back up your projects and samples.
  2. Connect the FM-1 by USB, open the install page in Chrome or Edge, and go to Device update.
  3. Click Connect device, then Start update. On other firmware, choose Enable force flash and reconnect first.
  4. In Projects & sounds, write the built-in samples to the device to load the 909 kit.
